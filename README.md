# React Hooks & Full Stack Web Development Practice

Welcome to my learning repository! This project contains my practical exercises and implementation of core React concepts, specifically focusing on **React Hooks**, alongside various full-stack web development components.

## 🚀 Key Features Practiced
* **useState:** Managing local component state, counters, and form inputs.
* **useEffect:** Handling side effects, rendering logic, and mimicking lifecycle methods.
* **Component Architecture:** Creating reusable UI parts like `ProjectCard`, `ProjectForm`, and dynamic pages.

## 📁 File Structure Overview
* `/useState.js` & `/useEffect.js` - Dedicated practice files for core React Hooks logic.
* `ProjectPage.jsx` & `ProjectCard.jsx` - Reusable React components applying hooks in a real-world scenario.
* `.vscode/launch.json` - Configuration for debugging the application smoothly in Google Chrome.

## 🛠️ Built With
* React.js
* JavaScript (ES6+)
* Vite / HTML5 / CSS3
